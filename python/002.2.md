# Python 2.2 — Higher-Order Functions, Lambda & Functional Tools

## 1. First-Class Functions

Python functions are **first-class objects**.

This means functions can be:

* Assigned to variables
* Passed as arguments
* Returned from functions
* Stored in data structures

Example:

```python
def square(x):
    return x * x

f = square

print(f(5))
# 25
```

Here:

```python
f = square
```

makes `f` another reference to the same function object.

```python
f is square
# True
```

---

# 2. Higher-Order Functions

A **higher-order function (HOF)** is a function that:

1. Takes another function as an argument, or
2. Returns another function.

---

## Function as an Argument

```python
def square(x):
    return x * x

def apply_operation(func, value):
    return func(value)

result = apply_operation(square, 5)

print(result)
# 25
```

Conceptually:

```text
square
   ↓
function object
   ↓
passed to apply_operation()
   ↓
func refers to square
   ↓
func(5)
   ↓
25
```

Inside:

```python
func(value)
```

is effectively:

```python
square(5)
```

---

# 3. Function Returning Another Function

```python
def create_multiplier(n):

    def multiply(x):
        return x * n

    return multiply
```

Now:

```python
double = create_multiplier(2)
triple = create_multiplier(3)

print(double(5))
# 10

print(triple(5))
# 15
```

`create_multiplier()` returns a function.

Therefore it is also a higher-order function.

The fact that `multiply()` remembers `n` leads to the concept of **closures**, which is covered separately.

---

# 4. Why Higher-Order Functions Are Useful

They allow behavior to be passed into another function.

Example:

```python
def apply_operation(func, numbers):
    return [func(x) for x in numbers]

def square(x):
    return x * x

def cube(x):
    return x * x * x

numbers = [1, 2, 3]

print(apply_operation(square, numbers))
# [1, 4, 9]

print(apply_operation(cube, numbers))
# [1, 8, 27]
```

`apply_operation()` doesn't need to know what operation is being performed.

The behavior is supplied through `func`.

This pattern is useful in:

* Callbacks
* Decorators
* Middleware
* Event handlers
* Framework APIs
* Functional programming

---

# 5. First-Class Function vs Higher-Order Function

These concepts are related but different.

### First-class function

Describes a **property of functions**.

Python allows functions to be treated like values/objects.

```python
f = square
```

### Higher-order function

Describes a **function that operates on other functions**.

```python
def apply(func, value):
    return func(value)
```

### Relationship

```text
First-class functions
        ↓
Functions can be passed/returned
        ↓
Higher-order functions
```

---

# 6. Important Function-Passing Trap

Consider:

```python
def square(x):
    return x * x

def apply(func, value):
    return func(value)
```

Correct:

```python
apply(square, 5)
```

Here we pass the function itself.

Incorrect:

```python
apply(square(5), 10)
```

Because:

```python
square(5)
```

executes immediately and returns:

```text
25
```

So this effectively becomes:

```python
apply(25, 10)
```

But `apply()` expects a callable as its first argument.

# 7. Lambda Functions

A **lambda** is a concise way to create a function without explicitly defining it using `def`.

Syntax:

```python
lambda arguments: expression
```

Example:

```python
square = lambda x: x * x

print(square(5))
# 25
```

Equivalent normal function:

```python
def square(x):
    return x * x
```

---

# 8. Lambda Is Still a Function Object

```python
double = lambda x: x * 2

print(type(double))
# <class 'function'>
```

So lambda doesn't create a special non-function object.

It creates a normal Python function object.

---

# 9. Lambda with Multiple Arguments

```python
multiply = lambda a, b: a * b

print(multiply(3, 4))
# 12
```

Multiple parameters are allowed.

---

# 10. Lambda Has an Implicit Return

Normal function:

```python
def add(a, b):
    return a + b
```

Lambda:

```python
add = lambda a, b: a + b
```

The expression result is automatically returned.

You don't write an explicit `return` inside a lambda.

---

# 11. Lambda Body Is One Expression

Valid:

```python
square = lambda x: x * x
```

Valid:

```python
maximum = lambda a, b: a if a > b else b
```

Invalid style/syntax for normal multi-statement logic:

```python
# ❌ Don't write a multi-statement function like this
lambda x:
    y = x * 2
    return y
```

If logic becomes complicated, use `def`.

---

# 12. Why Lambda Is Useful

Lambda is particularly useful when a higher-order function needs a small function.

For example:

```python
numbers = [1, 2, 3, 4]

result = map(
    lambda x: x * 2,
    numbers
)

print(list(result))
# [2, 4, 6, 8]
```

Instead of creating a separate function:

```python
def double(x):
    return x * 2
```

we can define the small operation inline.

---

# 13. Lambda with `sorted()`

Very common practical usage:

```python
users = [
    {"name": "A", "age": 30},
    {"name": "B", "age": 20},
    {"name": "C", "age": 25}
]

users.sort(key=lambda user: user["age"])
```

Result:

```python
[
    {"name": "B", "age": 20},
    {"name": "C", "age": 25},
    {"name": "A", "age": 30}
]
```

The lambda provides the **sorting key**.

---

# 14. `map()`

`map()` applies a function to every element of an iterable.

```python
def square(x):
    return x * x

numbers = [1, 2, 3, 4]

result = map(square, numbers)

print(list(result))
# [1, 4, 9, 16]
```

Conceptually:

```text
1 → square(1) → 1
2 → square(2) → 4
3 → square(3) → 9
4 → square(4) → 16
```

### Important

`map()` returns an **iterator**, not a list.

Therefore we commonly use:

```python
list(result)
```

to materialize the values into a list.

---

# 15. `map()` with Lambda

```python
numbers = [1, 2, 3, 4, 5]

result = map(
    lambda x: x * 2,
    numbers
)

print(list(result))
# [2, 4, 6, 8, 10]
```

The lambda is applied to every element.

---

# 16. `filter()`

`filter()` selects elements based on a condition.

The function passed to `filter()` should return a truthy/falsy value.

Example:

```python
numbers = [1, 2, 3, 4, 5]

def is_even(x):
    return x % 2 == 0

result = filter(is_even, numbers)

print(list(result))
# [2, 4]
```

Conceptually:

```text
1 → False → discard
2 → True  → keep
3 → False → discard
4 → True  → keep
5 → False → discard
```

---

# 17. `filter()` with Lambda

```python
numbers = [1, 2, 3, 4, 5, 6]

result = filter(
    lambda x: x > 3,
    numbers
)

print(list(result))
# [4, 5, 6]
```

The lambda returns:

```text
1 → False
2 → False
3 → False
4 → True
5 → True
6 → True
```

---

# 18. `map()` vs `filter()`

### `map()`

> Transform every element.

```python
map(lambda x: x * 2, numbers)
```

Generally produces one output for each input.

### `filter()`

> Select elements based on a condition.

```python
filter(lambda x: x > 3, numbers)
```

Can produce fewer elements than the input.

### Easy distinction

```text
map    → "What should this element become?"
filter → "Should this element remain?"
```

---

# 19. `reduce()`

`reduce()` progressively combines elements into an accumulated result.

It is available from `functools`.

```python
from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(
    lambda x, y: x + y,
    numbers
)

print(result)
# 10
```

Execution:

```text
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
```

The previous result becomes the first argument for the next operation.

---

# 20. `reduce()` with Multiplication

```python
from functools import reduce

numbers = [2, 3, 4]

result = reduce(
    lambda x, y: x * y,
    numbers
)

print(result)
# 24
```

Execution:

```text
2 × 3 = 6
6 × 4 = 24
```

---

# 21. `reduce()` with Initial Value

`reduce()` can optionally take an initial value.

```python
from functools import reduce

numbers = [2, 3, 4]

result = reduce(
    lambda x, y: x * y,
    numbers,
    10
)

print(result)
```

Execution:

```text
10 × 2 = 20
20 × 3 = 60
60 × 4 = 240
```

Output:

```text
240
```

Syntax:

```python
reduce(function, iterable, optional_initial_value)
```

---

# 22. `map` vs `filter` vs `reduce`

| Function   | Purpose                     | Typical Output      |
| ---------- | --------------------------- | ------------------- |
| `map()`    | Transform each element      | Many values         |
| `filter()` | Select elements             | Zero or more values |
| `reduce()` | Accumulate/combine elements | Usually one value   |

Example:

```text
map:
[1, 2, 3] → [2, 4, 6]

filter:
[1, 2, 3, 4] → [2, 4]

reduce:
[1, 2, 3, 4] → 10
```

# 23. Lambda with Conditional Expression

Lambda can contain a conditional expression.

```python
numbers = [1, 2, 3, 4, 5, 6]

result = list(
    map(
        lambda x: x * 2 if x % 2 == 0 else x,
        numbers
    )
)

print(result)
# [1, 4, 3, 8, 5, 12]
```

Logic:

```text
even → multiply by 2
odd  → leave unchanged
```

---

# 24. Lambda with `filter()`

```python
numbers = [1, 2, 3, 4, 5, 6]

result = list(
    filter(
        lambda x: x % 2 == 0,
        numbers
    )
)

print(result)
# [2, 4, 6]
```

Here the lambda returns `True` only for even numbers.

# 25. Lambda with `sorted()`

```python
numbers = [5, 2, 8, 1, 3]

result = sorted(
    numbers,
    key=lambda x: -x
)

print(result)
# [8, 5, 3, 2, 1]
```

The lambda produces the sorting key:

```text
5 → -5
2 → -2
8 → -8
1 → -1
3 → -3
```

`sorted()` sorts keys in ascending order:

```text
-8, -5, -3, -2, -1
```

which results in the original values being displayed in descending order.

### Important

The lambda isn't directly telling `sorted()` to sort descending.

It is providing a **key function**.

# 26. Lambda vs `def`

| Feature             | `lambda`                             | `def`                 |
| ------------------- | ------------------------------------ | --------------------- |
| Creates function    | Yes                                  | Yes                   |
| Explicit name       | No                                   | Yes                   |
| Multiple parameters | Yes                                  | Yes                   |
| Multiple statements | No                                   | Yes                   |
| Explicit `return`   | No                                   | Yes                   |
| Best use            | Small operations                     | General/complex logic |
| Common usage        | `map`, `filter`, `sorted`, callbacks | General functions     |

### Practical rule

> Use lambda for short, immediately understandable operations. Use `def` when the function is complex enough to deserve a name or multiple statements.

# 27. Interview Traps

### Trap 1 — Lambda is not a function

Incorrect:

> Lambda is a special operation.

Correct:

> A lambda expression creates a function object.

---

### Trap 2 — Lambda is always faster

Incorrect:

> Lambda is used for performance.

Correct:

> Lambda is primarily a concise way to define a small function. It is not inherently a performance optimization.

---

### Trap 3 — Lambda accepts only one argument

Incorrect.

This is valid:

```python
lambda a, b: a + b
```

---

### Trap 4 — Overusing lambda

Avoid complicated lambdas.

If the logic is difficult to read:

```python
def calculate_score(user):
    ...
```

is usually better.

# 28. Interview-Ready Definitions

### First-class function

> A function that can be treated like a normal object/value: assigned, passed, stored, or returned.

### Higher-order function

> A function that accepts another function as an argument or returns another function.

### Lambda

> A concise anonymous function expression whose body consists of a single expression whose result is implicitly returned.

### `map()`

> Applies a function to each element of an iterable and returns an iterator containing the transformed results.

### `filter()`

> Applies a predicate to elements of an iterable and returns an iterator containing elements for which the predicate is truthy.

### `reduce()`

> Repeatedly combines elements of an iterable using an accumulator function to produce a final accumulated result.

# 30. Core Rules to Remember

1. Functions are first-class objects.
2. Higher-order functions take or return functions.
3. Lambda creates a function object.
4. Lambda is best for small operations.
5. `map()` transforms elements.
6. `filter()` selects elements.
7. `reduce()` accumulates elements.
8. `map()` and `filter()` return iterators.
9. `sorted(key=...)` accepts a function that determines the sorting key.
10. Passing `square` and passing `square(5)` are completely different:

* `square` → function object
* `square(5)` → return value
